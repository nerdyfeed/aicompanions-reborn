# AI Companion: зрение по клавише V (Minecraft 1.20.1)

## Что добавлено

- Клавиша **V** делает один скриншот текущего кадра Minecraft.
- Скриншот отправляется в OpenAI-compatible vision endpoint; по умолчанию это Ollama с `qwen2.5vl:3b`.
- В запрос vision-модели также входят здоровье игрока, координаты, измерение, до 4 ближайших живых мобов в радиусе 24 блоков и до 5 первых непустых предметов инвентаря.
- Краткое описание картинки и сжатые игровые данные отправляются компаньону через существующий чат-механизм мода. Голосовой ввод по **F** остаётся внешним скриптом и не изменён.
- Анализ запускается только по нажатию V. Одновременно допускается только один запрос.

## Установка модели в Ollama

На машине, где работает Ollama:

```bash
ollama pull qwen2.5vl:3b
```

Проверьте модель напрямую, прежде чем запускать Minecraft:

```bash
ollama run qwen2.5vl:3b
```

## Настройка endpoint

При первом нажатии V мод создаёт файл:

`config/aicompanion/vision.json`

Пример:

```json
{
  "endpoint": "http://localhost:11434",
  "model": "qwen2.5vl:3b",
  "apiKey": "",
  "timeoutMs": 60000
}
```

`endpoint` — базовый адрес **без** `/v1` в конце. Мод сам добавляет `/v1/chat/completions`.

Если Minecraft и Ollama работают на разных компьютерах, укажите LAN-IP Ubuntu-сервера, например `http://192.168.1.50:11434`, вместо `localhost`. Ollama по умолчанию часто слушает только localhost; если нужно открыть доступ по LAN, настройте `OLLAMA_HOST=0.0.0.0:11434` и ограничьте firewall доступом только из своей локальной сети. Не открывайте порт 11434 в интернет.

Если endpoint требует токен, укажите его в `apiKey`. `timeoutMs` можно увеличить при медленной генерации, максимум в коде ограничен 180000 мс.

## Сборка

Требуется JDK 17 и доступ к Gradle/Maven-репозиториям при первой сборке. Из каталога `aicompanion`:

**Windows PowerShell:**

```powershell
.\gradlew.bat build
```

**Linux/macOS:**

```bash
chmod +x ./gradlew
./gradlew build
```

Готовый mod JAR появится в `aicompanion/build/libs/`. Установите его вместо предыдущего JAR в клиентский каталог `mods` и оставьте совместимыми остальные версии Fabric/API и Minecraft 1.20.1.

## Ограничения и примечания

- Этот патч рассчитан на исходный проект Fabric для Minecraft 1.20.1.
- Для вызова компаньона используется текущий чат-механизм, поэтому короткое сообщение с описанием экрана и игровыми данными будет видно в игровом чате и может быть видно другим игрокам. Не нажимайте V на сервере, если не хотите отправлять это сообщение в общий чат.
- Из-за лимита длины игрового чата данные сокращаются: описание изображения до 60 символов, ближайшие мобы и инвентарь — до коротких списков. Vision-модель получает более полный набор данных.
- Скриншот отправляется на endpoint, указанный в `vision.json`. При использовании удалённого endpoint изображение покидает компьютер; используйте локальный доверенный сервер, если важна приватность.
- Сборка в среде подготовки не была завершена: Gradle wrapper не смог загрузить Gradle 8.10 из-за недоступности `services.gradle.org`/DNS. Сборку необходимо проверить на машине с доступом к Gradle-репозиториям.
